A home monitoring system and playground built around a Raspberry Pi 5 and a camera on a 3D-printed pan/tilt stand. A Python (Flask) backend runs on the Raspberry at my home and is exposed through a Cloudflare Tunnel, while this Angular frontend is hosted on GitHub Pages. The camera stream is available after signing in.
